## Navigation and interaction
The primary navigation links to every section and to the standalone cabinet. The standalone cabinet links back to the main page. The Tic-Tac-Toe board is intentionally a **CSS-only interaction demonstration**: the four empty cells can be toggled to show an X using a checkbox/label pattern. This does not claim to implement a full game engine; the assignment source requires HTML/CSS and explicitly says JavaScript is not the focus.

## Checkpoint coverage
1. Flexbox — header/navigation/cabinet controls.
2. CSS Grid — 3×3 Tic-Tac-Toe board and responsive card grids.
3. Keyframe animation — 0%, 50%, 100% stages, transform, delay, and fill mode.
4. Positioning + z-index — layered composition with explicit stacking.
5. Micro-interactions — hover/focus-visible states and CSS-only board toggles.
6. Responsive/professional styling — external CSS, variables, semantic HTML5, multiple breakpoints, and reduced-motion support.
